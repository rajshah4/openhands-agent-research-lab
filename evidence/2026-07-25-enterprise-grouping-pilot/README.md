# Public evidence: Enterprise sandbox grouping pilot

This bundle records the bounded live test of OpenHands Enterprise's supported
`Group by Newest` sandbox strategy.

Summary:

- five first-class Enterprise conversations;
- one shared sandbox;
- five independently valid candidates;
- two conversations executed concurrently;
- one active sandbox at peak;
- zero active sandboxes after a pool-level pause;
- no access to OpenHands internal database tables.

The conversation links and immutable IDs are in
[results.json](results.json). Prompts, model responses, credentials, session
keys, user identifiers, and runtime hostnames are not included.

The experiment protocol and operational conclusions are documented in
`experiments/enterprise-sandbox-grouping/`.
